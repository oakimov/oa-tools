# MiMo Code Review

Comparison of [MiMo Code](https://github.com/XiaomiMiMo/MiMo-Code) (Xiaomi) against upstream [OpenCode](https://github.com/anomalyco/opencode).

See **[MIMO_RESEARCH.md](MIMO_RESEARCH.md)** — architecture lineage, what MiMo kept, what it added/changed, and how it differs from OpenCode today.

**Bottom line:** MiMo is a TUI-first OpenCode fork optimized for long-horizon agent work (memory, checkpoints, compose/workflows, `/goal`, max-mode, dream/distill), rebranded to `@mimo-ai/*` with Xiaomi-hosted defaults — not a ground-up rewrite.
