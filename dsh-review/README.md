# DeepSeek Harness Review

Review of [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`) — the agent harness from DeepSeek AI — compared against the previously reviewed products (OpenCode, MiMo, Kilo, ZCode, CoStrict).

See **[DSH_RESEARCH.md](DSH_RESEARCH.md)** — origin/timeline, Cordis "everything is a plugin" architecture, plugin model vs the OpenCode family, OS-level sandbox, telemetry posture (opt-in, default-off), providers, product surfaces, and engineering posture.

**Bottom line:** DeepSeek Harness is **not a fork** of anything in the reviewed family — it is an independent, from-scratch TypeScript agent harness built on a vendored copy of the Cordis plugin framework, where *everything* (model adapter, tool registry, session log, approval policy, even telemetry) is a swappable Cordis plugin. Launched publicly 2026-08-13 after ~2 months of pre-public development (~12.3k commits), it went to ~114k stars / ~11k forks within 48 hours. Its differentiators vs. the OpenCode class: **real OS-enforced sandboxing on all three platforms by default** (Landlock/bwrap, macOS Seatbelt, Windows restricted-token ACL), **telemetry that is off by default** (the only product of the six with default-off sharing), and an **agent-authored, doc-gated engineering process** (agent notes, ~35 verify-* gates, per-file 100% coverage) — at the cost of an explicit "developer preview" guarantee of breaking changes and no long-term ABI promise yet.

**Telemetry:** Export is **opt-in via `DSH_TELEMETRY_MODE`** (`FULL` / `FEEDBACK_ONLY`), default `DISABLED`; `DSH_TELEMETRY_DISABLED` (any value) forces it off process-wide. Uploads (when enabled) target `https://harness-telemetry.deepseeksvc.com/v1/logs` (OTLP/HTTP) unless `DSH_TELEMETRY_OTLP_URL` overrides it, carry complete session-log event bodies, and ship **no built-in redaction rules**. An anonymous per-home UUID (`$DSH_HOME/.anonymous-user-id`) is sent to DeepSeek's own model API as the `x-deepseek-harness-user-id` header regardless of telemetry mode — see [DSH_RESEARCH.md §7](DSH_RESEARCH.md#7-telemetry--network--privacy).
